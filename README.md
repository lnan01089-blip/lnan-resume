# N'RESUME · 廖楠的个人主页

N'RESUME 是廖楠的单页静态求职主页，用来展示教育、工作与校园经历、项目、技能、兴趣爱好与联系方式。视觉采用「暖灰纸上编辑」风格：`#F4F5F8` 暖灰画布、白色大圆角卡片、宋体大标题与数字、胶囊按钮、圆形头像、手绘 IP 小人、黑色联系卡，以及项目多图灯箱与可散开的兴趣图片卡牌。

首屏、页头、页脚、浏览器标题与社交分享封面统一使用 N'RESUME 名称，廖楠 / LIAO NAN 作为副标保留个人识别。

内容严格以根目录简历 PDF 为准，不虚构经历、时间、论文数量或项目结果。年龄、性别、党员身份默认不展示。

## 技术栈

原生 HTML + CSS + JavaScript，无框架、无构建步骤、无后端。

字体自托管：

- **Inter** 400 / 500 / 600（`assets/fonts/inter-latin-*.woff2`），用于正文、标签、按钮与导航。
- **Noto Serif SC** 500（`assets/fonts/noto-serif-sc-500.woff2`），仅保留页面实际用到的字符，约 100KB，用于标题、姓名、数字与联系卡大标题。

中文字符若不在子集内会回落到系统的苹方 / 宋体 / 微软雅黑。新增中文文案后，需要重新生成宋体子集；否则新字会以回退字体显示。

## 交互

- **经历手风琴**：三段工作经历默认全部展开；点击标题可独立收起或展开，不影响其他段落。按钮带 `aria-expanded`，关闭面板为 `inert`。
- **图片替换面板**：页脚「替换图片」入口会打开图片管理器，包含头像、IP、兴趣图片 9 个单图位置，以及 3 个项目的多图画廊；选择本地图片后立即预览，并保存在当前浏览器。每个位置和每张项目图片都带备注输入框，最多 80 字。
- **图片备注**：项目图片和兴趣图片的备注会显示在对应灯箱的图片下方；头像与 IP 的备注会作为页面图片的悬停提示，同时保留在管理器中方便识别。备注和图片一样只保存在当前浏览器。
- **项目文字编辑**：项目区右上角「编辑文字」或页脚同名入口进入编辑模式，可直接点击卡片中的类型、标题、描述、数据、成果和标签修改。修改自动保存在当前浏览器，并同步到项目图片入口、灯箱和图片管理器；点击「恢复默认文字」可清除全部文字覆盖。
- **项目图片灯箱**：点击项目卡片右上角缩略图打开。支持左右箭头、缩略图跳转、`←` / `→` / `Home` / `End` 键以及手机左右滑动；显示当前序号与单图备注。
- **灯箱**：项目多图与兴趣卡牌共用；按钮、遮罩或 Esc 关闭，带焦点陷阱、焦点返回与背景 `inert`。
- **兴趣爱好卡牌**：无分类筛选；堆叠状态下点击任意卡牌，六张照片会散开成完整网格，一眼看全所有内容；散开后点击单张照片打开大图灯箱，点击「收起卡牌」回到堆叠。底部按钮带 `aria-expanded`，键盘与读屏可获知展开状态。
- **邮箱复制**：一键复制并弹出轻提示，失败时回退到手动选择。
- **手机菜单**：全屏抽屉、Esc 关闭、焦点陷阱、背景滚动锁定，点击链接后平滑滚动到对应章节。
- **滚动反馈**：页头在滚动后出现毛玻璃与细线；导航随章节高亮。
- **动效降级**：`prefers-reduced-motion` 下关闭入场、位移与平滑滚动。

## 素材替换

### 页面内预览

滚动到页脚，点击 **替换图片**，即可打开图片管理器：

- 支持头像、圆形 / 全身 IP、6 张兴趣图片，以及 3 个项目的多图画廊。
- 单图位置可直接选择图片替换；项目画廊支持「添加图片」「替换」「移除」，每个项目最多 8 张、至少保留 1 张。
- 每张图片都有备注输入框，最多 80 字；项目图片和兴趣图片的备注会显示在图片弹窗中，头像与 IP 的备注会作为页面图片的悬停提示。
- 图片会压缩到最长边 1200px，并以 WebP 保存在当前浏览器的 `localStorage`。单图键前缀为 `nresume:image:`，项目画廊为 `nresume:gallery:`（值为包含 `src` / `alt` / `caption` 的图片对象数组），单图备注为 `nresume:note:*`。
- 可对单个位置选择「恢复默认」，也可一键「全部恢复默认」；恢复会同时清空对应的图片备注。
- 只接受 JPG / PNG / WebP / AVIF 栅格图片，不接受 SVG / GIF，单张上限 20MB。
- 关闭面板或刷新页面后，替换仍会保留在**当前浏览器**中；其他访客看到的仍是 `assets/img` 中的原图。

因此，页面内替换适合先看效果。要让所有访客看到新素材，请用下面的方式覆盖仓库文件并重新部署。

### 项目文字

- 项目区的「编辑文字」会进入 `contenteditable` 编辑模式，卡片结构与图片入口保持不变。
- 文字覆盖按项目保存在 `nresume:project-text:<project-key>`，仅记录与默认文案不同的字段；刷新后仍保留在当前浏览器，不会影响其他访客。
- 「恢复默认文字」会删除所有项目的文字覆盖；退出编辑模式时，空字段会回退到默认文案，并执行长度上限与空白整理。

### 覆盖仓库文件

- **头像**：替换 `assets/img/avatar-720.jpg`（720 × 720）与 `avatar-360.jpg`（360 × 360），保持 1:1 正方形、人物居中。
- **兴趣爱好照片**：建议统一 3:4 竖图，主体居中；替换 `life-1.webp` … `life-6.webp`，并同步 `index.html` 中卡牌的 `src` / `data-img` 与 `alt`。
- **项目图片**：建议 16:10 横图；替换 `project-stashly-*.webp`、`project-research-*.webp`、`project-site-*.webp`。默认图片清单在 `assets/js/main.js` 的 `PROJECT_GALLERIES` 中维护。
- **个人 IP**：替换 `ip-nan.png`（全身）或 `mascot-head.png`（圆形头像），保持透明背景。
- **社交分享图**：替换 `assets/img/og-cover.png`，尺寸保持 1200 × 630。
- **Favicon**：替换 `assets/img/favicon.png`。

替换图片时保留现有 `width`、`height`、`loading` 与 `alt` 属性，避免布局跳动并保持无障碍语义。

### 重新生成宋体子集

安装了 `fonttools` 后，可从完整 Noto Serif SC 字体中按页面字符生成子集：

```bash
pyftsubset NotoSerifSC-Regular.otf \
  --text-file=page-chars.txt \
  --flavor=woff2 \
  --output-file=assets/fonts/noto-serif-sc-500.woff2
```

`page-chars.txt` 应包含 `index.html`、`main.js` 与 CSS 中出现的全部字符。修改文案后重新执行，并确认页面上的宋体没有回退。

## 无障碍与质量

- 跳过导航链接、可见的 2px 焦点环、`aria-current`、`aria-expanded`、`aria-pressed`、`aria-controls`。
- 项目图片入口带 `aria-haspopup="dialog"`；灯箱中的上一张 / 下一张按钮、缩略图与 `aria-live` 序号播报均有明确标签。
- 灯箱支持方向键、Home / End、手机滑动、Tab 焦点陷阱、焦点返回与背景 `inert`。
- 图片管理器为模态对话框，焦点限制在面板内；关闭后回到页脚入口，项目图片操作后焦点回到对应按钮。每个备注输入框都有明确的无障碍标签。
- 项目图片与兴趣图片的备注会同步到灯箱说明和缩略图的 `aria-label`；重置后恢复默认备注。
- 项目文字字段在编辑模式下带 `role="textbox"` 与「编辑项目名称」等无障碍标签；Enter 完成当前字段，Esc 退出编辑模式，标签变化会同步到图片入口与管理器。
- 兴趣卡牌在堆叠状态下只让可见卡牌进入 Tab 顺序；展开后六张全部可聚焦，卡牌名称会从「展开全部」切换为「查看 … 打开大图」，收起按钮同步更新 `aria-expanded`。
- 正文使用 `#61636A`，辅助索引使用 `#8D8F96`；信息不依赖颜色单独传达。
- 图片带替代文本、显式尺寸与懒加载；无 JS 时内容仍然可见。
- 目标：Lighthouse Performance、Accessibility ≥ 90。
